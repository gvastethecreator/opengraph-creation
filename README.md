# Open Graph Creation

Agent Skill for Open Graph images and social link previews. It builds a project-owned image pipeline and page metadata. It does not integrate hosted card-generation services.

## Quick start

```text
npx skills add gvastethecreator/opengraph-creation
```

Copy `SKILLS/opengraph-creation` into the skill directory your agent already loads. Then ask to create, repair, or diagnose share cards for a public page.
